会員登録

arrow_downward

  1. AnalyWalletにアクセスします。

  2. 「新規登録はこちら」ボタンをクリックし、メールアドレス・パスワードを入力します。利用規約とプライバシーポリシーに同意の上、「送信する」ボタンをクリックしてください。

  3. 入力したメールアドレスに、以下のようなメールが届きますのでご確認ください。

    info

    届かない場合は、メールアドレスが間違っていないかご確認ください。

  4. 以下のような画面になれば登録完了です。

カテゴリーのカスタマイズ

arrow_downward

  1. 画面右上のメニューアイコンをクリックします。

  2. カテゴリー名を入力し、「追加する」ボタンをクリックします。

  3. 以下のように、カテゴリーが追加されれば成功です。

    この例の場合は、支出に「食費」「交際費」「交通費」「趣味」「その他支出」カテゴリー、収入に「バイト」「その他収入」カテゴリーをそれぞれ追加しています。

    info

    支出も収入も、登録方法は同じです。

    info

    調整用カテゴリーについて

    調整用カテゴリーを用いると、ダッシュボード内の収入に含めずに、直接「現在の残高」に登録することができます。なお、調整用カテゴリーには「調整用」と書かれたバッチが付きます。

    この例の場合、カテゴリー「調整用カテゴリー」に登録した5万円が、ダッシュボードの収入にはカウントされず、「現在の残高」に直接追加されています。

    初回の登録時や、ずれた際の調整などにご利用ください。

arrow_downward

  2. 登録フォームに従って入力します。カテゴリーには、カテゴリー設定で登録したカテゴリーを選択できます。

  3. 以下のような画面になり、登録履歴に登録されていれば完了です。

    info

    支出も収入も、登録方法は同じです。

サブスク設定

arrow_downward
  1. info

    サブスク設定について

    あらかじめ指定した日に、毎月一定額を自動で登録システムです。登録時に「サブスク」カテゴリーが自動で生成され、データはその中に保存されます。

    画面右上のメニューアイコンをクリックします。

  2. サイドメニューで「サブスク管理」をクリックします。

  3. サービス名・金額・支払日を入力します。支払日に入れた日にちに、自動で登録されます。この例の場合は、毎月23日にAnalyWallet上に追加されます。

  4. 「追加する」を押して、以下のようにリストに追加されれば完了です。

    info

    サブスクは複数個登録することができます。

  5. 指定した日にちになると、『メモ名（自動追加）』という形で自動追加されます。

  6. 削除する場合は、「削除する」ボタンをクリックしてください。

メールアドレスの変更

arrow_downward

  1. 画面右上のメニューアイコンをクリックします。

  2. サイドメニューで「アカウント設定」をクリックします。

  3. 「メールアドレス」の欄に、新しいメールアドレスを入力します。確認の上、「メールアドレスを変更する」ボタンをクリックしてください。

  4. 入力したメールアドレス宛に、確認メールが届きますのでご確認ください。確認の上、「メールアドレスを変更する」ボタンをクリックしてください。これにて変更完了です。

パスワードの変更

arrow_downward

  1. 画面右上のメニューアイコンをクリックします。

  2. サイドメニューで「アカウント設定」をクリックします。

  3. 「パスワード」の欄に、現在のパスワードと新しいパスワードを入力します。確認の上、「パスワードを変更する」ボタンをクリックしてください。

  4. 登録されているメールアドレス宛に、確認メールが届きますのでご確認ください。これにて変更完了です。

二段階認証の設定

arrow_downward

  1. AnalyWalletでは、二段階認証の設定を行うことができます。

    画面右上のメニューアイコンをクリックします。

  2. サイドメニューで「アカウント設定」をクリックします。

  3. 「二段階認証（MFA）」の欄にある、「二段階認証を有効にする」ボタンをクリックします。

  4. キーが発行されるので、利用している二段階認証アプリの該当する欄にコピー＆ペーストしてください。

    info

    画像では、Proton Passを用いています。

  5. 二段階認証アプリの6桁のコードを、AnalyWallet上で入力してください。

  6. 以下のような画面になれば設定完了です。

    info

    バックアップコードは、アカウントにアクセスできなくなった場合に用いる重要なものです。必ずメモしてください。

アカウントの削除

arrow_downward

  1. 画面右上のメニューアイコンをクリックします。

  2. サイドメニューで「アカウント設定」をクリックします。

  3. 一番下の「アカウント設定」の欄で、「アカウントを削除する」ボタンをクリックします。

  4. パスワードを入力して、「削除する」ボタンをクリックしてください。これにて完了です。
